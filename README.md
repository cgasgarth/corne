# Corne configuration

My keyboard configuration, exported from the connected device in Vial Web on 2026-10-20. Vial identifies the device as **Cornix**.

## Backup

`corne.vil` is the native Vial export. It contains 10 keymap layers, encoder mappings, macros, tap dance, combos, and QMK settings.

## Restore

1. Connect the matching keyboard and open Vial Web at <https://vial.rocks/>.
2. Select the keyboard.
3. Select **File → Load saved layout…** and open `corne.vil`.

Loading a layout writes the configuration to the keyboard. Save its current layout first if you need a backup.

## Update

Use **File → Save current layout…** to replace `corne.vil`, then commit and push the file.
